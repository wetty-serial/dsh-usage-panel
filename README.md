# dsh-usage-panel

左上のパネル一覧（プラグインと同じ並び）に「使用量」を足し、押すと中央に全画面ページで開く。プロバイダ（OpenCode Go / Claude / free-pool）の使用率と回復時刻を、ダッシュボードの JSON API から読んで一覧する。読み取り専用で、値は加工しない。

ページ左上の「＜」で、直前に開いていた画面（プラグイン／スケジュールなど）へ戻る。履歴が無ければ現在のセッションの会話に戻る。

## 何を読むか

取得先は同じホスト（nucbox）の `provider-usage-dashboard`、`http://127.0.0.1:18080/api/usage`。
応答は JSON で、少なくとも `providers` オブジェクトを持つこと。

## 提供元が増減しても壊れない

画面は応答の中身だけで組み立てる。

- `providers` のキーを全部そのまま並べる。既知のキー（`opencode_go` / `claude` / `free_pool`）は
  表示名と並び順だけ与える。知らないキーはキー名をそのまま見出しにする。
- 各提供元の `meters` は件数も `label` も決め打ちしない。空でも `status` と理由を出す。
- 提供元そのものが増減しても、`meters` の要素が増減しても、コード変更は要らない。
- 数値が無い枠は `—` と表示する。0 とは書かない。

## 取れないとき

- 取得に失敗したら数字は出さず、「使用量を取得できません」と理由（URL と HTTP ステータス等）を出す。
- 応答に `providers` が無い JSON は失敗として扱う。

## 設定

| フィールド | 既定 | 意味 |
|---|---|---|
| `url` | `http://127.0.0.1:18080/api/usage` | 取得先 |
| `timeoutMs` | `8000` | 上流の読み取りタイムアウト |
| `cacheSeconds` | `30` | 同じ結果を使い回す秒数（開いた複数ページで連打しない） |

ページを開いている間は 60 秒ごとに読み直す（タブが隠れている間は読まない）。「再取得」は 5 秒に 1 回まで。

## 入れ方

DSH のプラグイン管理から `github:wetty-serial/dsh-usage-panel` を入れる。
